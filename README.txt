Xセフティ 1.3.1
==========================

【インストール】
1. ZIPをダウンロードして「すべて展開」します。
2. Chromeのアドレス欄に chrome://extensions/ を入力して開きます。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、
   manifest.json が入っている XSensitiveHide フォルダーを選びます。
5. 開いているXのタブを再読み込みします。

【旧版から更新するとき】
旧版を読み込んだフォルダーに、新しいZIPの中身を上書きします。
chrome://extensions/ で該当する拡張機能の再読み込みボタンを押し、
Xのタブを再読み込みします。同じChromeプロファイルの登録内容を
引き継ぐには、旧版の削除をせず、同じフォルダーで更新します。

【1.2.0の変更】
・拡張機能名を「Xセフティ」に変更しました。
・追加・変更された投稿を中心に判定し、画面付近の画像を1件ずつ処理します。
・画像取得には縮小版を使い、同じ画像の判定結果を再利用します。
・更新で古いタブとの接続が切れた際に処理を停止し、設定の読み込み失敗も扱います。
更新後はXのタブを再読み込みしてください。

【使い方】
・対象はPC版Chromeに表示されたXのポストとリプです。ポスト詳細の
  返信欄、プロフィール、検索結果、タイムラインで動作します。
・本文、#タグ、Xのセンシティブ警告、投稿画像・取得できる動画の
  サムネイルを判定します。動画の再生中の映像は判定しません。
・該当した投稿の投稿者を @ユーザー名 で自動保存し、その投稿と
  以後に読み込む同じアカウントのポストやリプを非表示にします。
・登録するのはX上でその投稿を書いたアカウントです。画像内の
  透かし、本文中のメンション、引用元から投稿者を推測しません。
  引用ポストは元のポストを開くと判定します。トレンド欄の単独の
  ハッシュタグには投稿者がないため、投稿内のタグを判定します。
・拡張機能のアイコンから登録理由を確認できます。誤検出した場合は
  「表示に戻す」で解除すると、自動登録の対象からも外れます。
  再び隠すには除外一覧から「非表示に戻す」を押します。
・独自のキーワードと #タグ は一行に一つ入力して保存できます。
  #付きの単語はタグのみ、#なしの単語は本文とタグの部分一致です。
  保存すると開いているXのタブにも反映します。別のChrome
  プロファイルを使う場合は、そのプロファイルで登録してください。
・「成人向け」「セックス」「性的な画像」などの初期判定語は、
  キーワードを登録していない状態でも有効です。
・動作を一時停止する場合は「自動検出と非表示を有効にする」をオフ
  にします。画像を判定しない場合は画像判定の項目だけオフにします。

【動作範囲】
この拡張機能は表示中のブラウザ内で判定・非表示にします。X公式の
ミュートやブロック設定は操作しません。アカウントの記録は、この
Chromeプロファイルに保存されます。画像の取得先はXの画像配信
サーバーです。画像や投稿本文を判定サービスへアップロードしません。
画像の誤検出・見落としは起こり得ます。取得できない画像は表示されます。
画像の判定にはCPUを使います。
前回の「X 返信先センシティブぼかし」とは別の拡張機能です。

【登録データを一つのファイルに保存・読み込み】
拡張機能のアイコンを押し、「ファイルに保存」を押すと、
XSafety-backup-日付.json がダウンロードされます。
保存済みの追加キーワード、#タグ、@ユーザー名、除外状態、登録理由を含みます。
別のChromeプロファイルでも「ファイルを読み込む」から同じJSONを選べます。
読み込みは既存データに追加します。重複したユーザー名は現在の状態を優先します。
ワードを編集中の場合は、先に「キーワードを保存」を押してください。

【1.3.1の修正】
画像取得・判定の一時失敗を安全な画像として記録せず、最大3回再試行します。
表示付近の投稿を3秒ごとに再確認し、遅れて読み込まれた投稿や
非表示用のクラスが外された投稿を再判定します。
article以外の要素で表示されるポストも判定します。
